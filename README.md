# Phillip Liems Portfolio

## Publish with GitHub Pages
1. Upload the contents of this folder to a GitHub repository.
2. In repository Settings > Pages, deploy from the main branch and root folder.
3. Replace the email and LinkedIn placeholders in `index.html`.
4. Add `assets/profile.jpg` and `assets/phillip-liems-resume.pdf`.

The portrait area includes a built-in fallback until a profile image is added.
